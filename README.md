# کاریاب — وب‌اپ در حال آزمایش

کاریاب یک وب‌اپ موبایل‌محور با ثبت‌نام، ورود، فرصت‌ها، کیف پول، درخواست برداشت، پشتیبانی و پنل مدیریت است. داده‌ها در PostgreSQL نگهداری می‌شوند. رابط کاربری در `public/`، مسیرهای API در `server.js` و ساختار پایگاه‌داده در `db/migrate.js` قرار دارند.

## اجرای توسعه

نسخهٔ Node.js موردنیاز طبق `package.json` حداقل ۱۸ است. پیش از اجرا، متغیرهای `DATABASE_URL`، `JWT_SECRET` و `ADMIN_PASSWORD` باید در محیط تنظیم شده باشند. هیچ رمز پیش‌فرضی در کد وجود ندارد؛ مقادیر محرمانه را در مخزن ثبت نکنید.

```sh
npm ci
npm run migrate
npm test
npm start
```

پس از اجرا، برنامه در `http://localhost:3000` و پنل مدیریت در `/admin.html` در دسترس است. مهاجرت پایگاه‌داده با دستور جداگانهٔ `npm run migrate` انجام می‌شود؛ `npm start` آن را اجرا نمی‌کند.

## وضعیت قابلیت‌ها

- ثبت‌نام، ورود، احراز هویت دستی، پشتیبانی، اعلان‌ها و رابط کیف پول پیاده‌سازی شده‌اند.
- رویدادهای ارائه‌دهندهٔ فرصت می‌توانند در سرور ثبت شوند و مبلغ را ابتدا به حالت در انتظار ببرند. نمایش مبلغ در کیف پول به‌تنهایی سند دریافت وجه از ارائه‌دهنده نیست.
- درخواست برداشت، بررسی مدیر و ثبت مرجع پرداخت وجود دارد. اتصال انتقال خودکار به HesabPay در `lib/payout-providers.js` پیاده‌سازی نشده است؛ ثبت وضعیت «پرداخت‌شده» توسط مدیر، راستی‌آزمایی مستقل انتقال پول نیست.
- برداشت‌هایی که مرجع یا شناسهٔ آن‌ها با `TEST` مشخص شده باشد، در تاریخچه برچسب آزمایشی دارند و از جمع برداشت‌های واقعی در آمار مدیریت کنار گذاشته می‌شوند. این برچسب همهٔ تراکنش‌های قدیمی آزمایشی را به‌طور خودکار شناسایی نمی‌کند.

## پیش از انتشار عمومی

مسیرهای ثبت فرصت، تطبیق کیف پول و برگشت رویداد باید با دادهٔ معتبر آزموده شوند. نسخهٔ فعال در Railway یا عبور تست‌های واحد به‌تنهایی اثبات درآمد یا پرداخت واقعی نیست.

# کاریاب — وب‌اپ کسب درآمد (نسخه MVP)

## این پروژه چیست
یک وب‌اپ کامل و کارکردی: ثبت‌نام، ورود، لیست تسک (فعلاً نمونه/mock)، کیف پول، درخواست برداشت،
و پنل ادمین برای تایید/رد برداشت‌ها.

## اجرای محلی (برای تست)
```
npm install
npm start
```
سپس در مرورگر باز کن: http://localhost:3000
پنل ادمین: http://localhost:3000/admin.html  (رمز پیش‌فرض: admin123)

## دیپلوی روی اینترنت (بدون نوشتن کد) — Railway
1. برو به https://railway.app و با گیت‌هاب یا ایمیل ثبت‌نام کن
2. "New Project" -> "Deploy from GitHub repo" یا آپلود مستقیم این پوشه
3. اگر گیت‌هاب نداری: یک ریپازیتوری جدید در https://github.com بساز، این پوشه را در آن آپلود کن
   (دکمه "Add file" -> "Upload files"، بدون نوشتن حتی یک خط کد)
4. در Railway این متغیرهای محیطی (Environment Variables) را تنظیم کن:
   - JWT_SECRET = یک رشته تصادفی طولانی و مخفی
   - ADMIN_PASSWORD = رمز قوی برای خودت (رمز admin123 پیش‌فرض را حتماً عوض کن)
5. Railway به‌صورت خودکار npm install و npm start را اجرا می‌کند و یک لینک عمومی (URL) به تو می‌دهد
6. همان لینک را با کاربران به اشتراک بگذار

## نکته مهم امنیتی قبل از عمومی کردن
- حتماً ADMIN_PASSWORD پیش‌فرض را عوض کن
- حتماً JWT_SECRET را به یک رشته تصادفی طولانی تغییر بده
- فایل data/db.json روی Railway پایدار نمی‌ماند مگر یک "Volume" اضافه کنی
  (تنظیمات Railway -> Volumes -> mount به /app/data) — این را قبل از عمومی کردن انجام بده
  وگرنه با هر ری‌استارت اطلاعات کاربران پاک می‌شود

## مرحله بعدی (وصل کردن شبکه واقعی CPA)
فایل server.js را باز کن، بخش MOCK_TASKS را پیدا کن — این‌جا باید با API واقعی شبکه‌هایی
مثل AdGate/OfferToro/CPX Research جایگزین شود. این کار را بعد از تایید شدن حساب Publisher
در آن شبکه‌ها انجام می‌دهیم.
